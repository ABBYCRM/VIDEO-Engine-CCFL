# Deploy (absorbed)

Aion-Brain runs as the `aion-brain` component of the VIDEO-Engine DigitalOcean
app (`video-engine-ccfl`). Source of truth is this folder in
`ABBYCRM/VIDEO-Engine-CCFL`.

Do not point `AION_BASE_URL` at `https://aion-brain-6iptg.ondigitalocean.app`.
That DigitalOcean app is another system's brain — leave it running.
Do not delete, archive, or modify GitHub `ABBYCRM/Aion-Brain`.

See `../../.do/app.yaml` and `../../docs/DIGITALOCEAN_ENV.md`.
