# Avatar Turnaround Standard

Use the image render API to create a standardized four-view turnaround sheet for each avatar.

## Required layout

- One canvas containing 4 equally sized panels.
- Panel order: Front, Left Side, Right Side, Back.
- Neutral standing pose.
- Consistent lighting, lens, scale, and wardrobe across all four views.
- Plain studio gray background.

## Clothing rules

### Female standard
- Tailored blazer or fitted professional top.
- Neutral-tone slacks or skirt appropriate for legal/newsroom content.
- No beachwear, lingerie, swimwear, or revealing fashion.

### Male standard
- Professional suit or business-casual outfit.

## Fidelity rules

- Preserve facial identity exactly across all views.
- Show hair silhouette accurately from every side.
- Maintain body proportions, accessories, and skin tone consistently.
- Ensure the turnaround sheet becomes the canonical reference for later video generation.
