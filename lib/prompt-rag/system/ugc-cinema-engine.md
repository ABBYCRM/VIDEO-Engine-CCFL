# UGC CINEMA ENGINE

This repository stores a reusable prompt library for campaign planning and one-shot prompt compilation.

## Global rules

- Prioritize photorealism > natural human behavior > product accuracy > storytelling > cinematic quality > spectacle.
- Videos should look like real footage captured with a real camera.
- Default format is 9:16 vertical.
- Preserve human anatomy, natural skin microtexture, physically coherent lighting, realistic eyes, stable hands, and temporal consistency.
- For PI campaigns, do not fabricate news reports, case results, testimonials, or legal guarantees.
- The same avatar identity must be preserved across all categories once selected.
- Female avatars in the default library must use professional wardrobe standards and never beachwear.
- Avatar onboarding requires a four-view turnaround image set: front, left side, right side, and back.
- If a newsroom background is used, supporting incident videos may appear full-screen, split-screen, on a TV wall, or as a green-screen background.
