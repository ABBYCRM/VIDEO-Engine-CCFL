# Research summary used for the scaffold

## DigitalOcean

Use App Platform as the managed app host and Managed Databases / Spaces for persistence instead of the ephemeral local filesystem on App Platform.

## Composio

Composio is a connected-tooling layer that supports user-scoped auth, tool discovery, triggers, and sessions across a large app catalog. It is an appropriate backbone for cross-app publishing and ads automation.

## Hedra

Hedra supports generating avatar videos from an image + audio workflow and exposes developer API endpoints for avatar generation and lip sync.

## NVIDIA

NVIDIA NIM and NeMo tooling provide relevant building blocks for monitor-AI work, including hosted models, observability, and evaluation services.

## Google Ads / Meta

The proper production path is official API integration through Google Ads API and Meta marketing surfaces, not scraping.
